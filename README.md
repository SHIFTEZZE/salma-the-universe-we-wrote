# SALMA — The Universe We Wrote

A self-contained, offline-capable memory experience. The site is `index.html`; it has no build step or external assets.

## Publish with GitHub Pages

1. Push the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. GitHub will show the published address in the Pages settings once deployment finishes.

The HTML includes selected personal conversation excerpts. Choose repository visibility with that in mind. The archive export itself and the separate memory inventory are not part of this deployment folder.
